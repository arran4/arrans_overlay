Title: Removal of app-misc/maid-appimage
Author: Arran <gentoo@arran4.com>
Posted: 2026-11-10
Revision: 1
News-Item-Format: 2.0
Display-If-Installed: app-misc/maid-appimage

The app-misc/maid-appimage package and its automatic update workflow have
been retired from this overlay.

The maintainer no longer uses Maid, and the package update pipeline has not
been maintained or independently checked for some time. To avoid presenting
an unverified package as maintained, new Maid AppImage updates will no longer
be supplied from this overlay.

Existing installed versions are not automatically removed. If you still
use Maid, consider obtaining a current release from its upstream project
or maintaining a separate ebuild. No replacement package is provided.

To remove the installed package if it is no longer needed:

  emerge --deselect app-misc/maid-appimage
  emerge --ask --depclean app-misc/maid-appimage
